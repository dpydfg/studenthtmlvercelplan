admin密码的正确bcrypt哈希值（salt rounds=10）

由于bcrypt每次生成的哈希值都不同（salt是随机的），建议使用在线工具生成：

推荐方法：使用在线工具生成
1. 访问 https://bcrypt-generator.com/
2. 在 "Password" 输入框中输入：admin
3. 在 "Rounds" 输入框中输入：10
4. 点击 "Generate Hash"
5. 复制生成的哈希值（60个字符，以 $2a$10$ 开头）

然后在Neon数据库中执行：

方法1：更新现有记录
UPDATE admins 
SET password_hash = '你生成的哈希值' 
WHERE username = 'admin';

方法2：删除后重新插入
DELETE FROM admins WHERE username = 'admin';
INSERT INTO admins (username, password_hash, created_at)
VALUES ('admin', '你生成的哈希值', NOW());

验证：
使用用户名 admin 和密码 admin 登录系统
